Here’s how it works.

When a new assignment arrives, forward the client’s order email to Matt. He replies in that thread with the partial-desk and full-desk rates and the return time.

Say it works and which one you want. Matt sends the link to that assignment’s private shared Drive folder. After the inspection, add your photos, sketch, notes, mobile report file and other agreed materials there, and we start.

We complete the agreed desk work and Matt personally reviews the report. The finished unsigned appraisal file lands in the same shared folder, ready to open in TOTAL. You review it, make any edits, sign it and send it to your client. Revisions within the agreed assignment go to the front of the line.

An example of what your day looks like.

You have three inspections today. You forwarded the client orders as they arrived, Matt replied to each with the rates and return time, you said yes to all three, and each got its own AP folder.

  1. 9:00 AM

    First inspection.

    When you’re done, add the photos, sketch, notes and mobile file to its AP folder. We start.

  2. 10:30 AM

    Second inspection.

    Add that packet to its own folder. The first one is already in research.

  3. 1:00 PM

    Third inspection.

    Add the last packet and head home.

  4. Later

    We handle the desk.

    Track each report while we research, build and review it. The finished unsigned appraisal file returns to the same AP folder at the agreed return time.

  5. Review

    You stay in control.

    Open the file in TOTAL, independently review it, make any edits, sign and deliver it to your client.
